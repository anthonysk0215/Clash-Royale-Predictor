# Clash Royale Predictor/Troop Analysis
This repository contains a dataset and Python scripts for analyzing troop data from a game like Clash Royale. The fun project focuses on cleaning, processing, and analyzing the dataset to extract meaningful insights, such as determineing how much elixir a fictional card may cost. The supervised classification machine learning models are from the sci-kit learn library.

Dataset originally from: https://www.kaggle.com/datasets/rodsaldanha/clash-royale-matches

## Features:
- Data Cleaning: Handles missing values and converts data types appropriately.

- Data Processing: Uses pandas to manipulate the dataset.

- Analysis & Insights: Extracts trends and patterns from the troop data.

## Installation:
Ensure you have Python installed. Then, clone this repository and install the required dependencies.
